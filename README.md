# Chiru — Julián Torres

Plan de trabajo de We Rock para C1 Entrenamiento Consciente y TACTO.

**En vivo:** https://werockagencia.github.io/chiru/

## Contenido
- `index.html` — plan maestro: pedidos, links, tablero y semana. El tablero se edita en la constante `TABLERO`.
- `estrategia/` — estrategia de los tres frentes y calculadora.
- `sitio/` — demo del sitio C1 y la membresía.
- `medellin/` — demo de la landing TACTO.
- `kit/` — mensajes, guiones de reels y pauta.
- `TEXTOS.md` — datos por confirmar.

## Antes de lanzar
- `sitio/js/c1.js`: WhatsApp y links de pago por plan.
- `medellin/index.html`: constantes `WHATSAPP` y `PAGO`.
- Quitar `noindex` de los HTML.

Config `chiru` en el `launch.json` de West 24 (php, puerto 5210).
